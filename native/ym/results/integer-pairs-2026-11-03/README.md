# Integer pairs and integer clocks

The operator was told: "Moving those fractions to integer pairs, and three live tools' timers to integer clocks, is on the open list". He answered: "handle the integer problem". His standing word on floating point: "Floating point should be redone to integer only. Not like redone as if erase the evidence, but say, hey, we need to do this again in integer only so that it works."

## What this holds

**The class.** [`intpair.py`](../../../scripts/intpair.py) is an exact signed reduced pair of Python ints. Division is the named function `qdiv(a, b)`. A float, a string, a fractional power or a float format spec raises `TypeError`. Its `hash()` agrees with CPython's rational class value for value, so sets and dicts iterate in the same order, and `hash(IntPair(n)) == hash(n)`.

**Its test.** [`test_intpair.py`](../../../scripts/test_intpair.py) runs every operation on both classes and compares value, kind and exception type. MEASURED: seeds 27, 28 and 29 at 200,000 rounds each, 52,562,547 comparisons, 0 failures, with values up to 3,000 bits, negative denominators, zero and denominators that are multiples of the hash modulus. `--teeth` breaks the class 14 ways, and all 14 are seen. It is the one live file that imports `fractions`, because that is its reference.

**The rewriter.** [`make_integer_pairs.py`](../../../scripts/make_integer_pairs.py) writes each copy from its original, comments and layout kept. By syntax tree, with the gate's own path-join rule, `a / b` becomes `qdiv(a , b)` and `x /= y` becomes `x = qdiv(x, y)`. The `fractions` import becomes `intpair`, with a `sys.path` line so the copy finds `native/scripts` from where it sits. Every other edit is a text pair in its table, asserted by count. A second path makes the same edits on the syntax tree and the two must dump the same. The second seat's four fuzzers go through [`make_integer_redo.py`](../3x4_stream/perron/second-seat/integer-redo/make_integer_redo.py) first, so that chain still reproduces. MEASURED: 25 copies, 35 divisions moved, regenerated byte-exact on Python 3.13 here and 3.12 here, each with 0 audit hits and 0 gate findings.

**The originals.** Every original stays byte-identical as the evidence of its run. `perron_climb.py` and `hash_store.py` keep the hashes in `RESULT_FILE` rows of `PERRON-RESULT.hbp`. `REDO-RUNS.hbp` and `CHECKED-DIVISIONS.hbp` stay as they are, and they describe the Fraction copies as they stood at commit `a1bb13c`, whose hashes are the `PRIOR_COPY` rows of [`RUNS.hbp`](RUNS.hbp).

**In place, as the brief names.** [`memory_pilot_runner.py`](../../python/memory_pilot_runner.py) moves to `time.monotonic_ns` with whole seconds, and its one bare path join to `joinpath`. It is dispatch only, so its `runlog` helper was read out of its source and run alone. The receipt `p4-41053502633` keeps the hash of the file as it ran then, `64ef70b9…`, at commit `a1bb13c` and before. [`indep_verify.py`](../../independent/indep_verify.py) moves `leading_minor_signs` from numpy to plain ints and lists, so it runs on the standard library alone. `indep_sqrt_check.py` still reads the recorded file from commit `cf6a2c9`, which needs numpy, so `indep-sqrt-check.yml` keeps installing it for that file alone.

**The gate.** [`no_float_gate.py`](../../../scripts/no_float_gate.py) now flags `fractions` too, and its own snippets include it. [`FLOAT-EVIDENCE.txt`](../../../scripts/FLOAT-EVIDENCE.txt) has a true count and reason on each row. The rows for `indep_verify.py`, `memory_pilot_runner.py` and the three upgraded copies are gone. `py_exact_t.py`, `py_verify_low.py`, `cap_check.py` and `test_intpair.py` are new rows, since the gate now sees their import. `no-float.yml` plants two fractions imports, and runs the differential test, the teeth and the byte-exact regeneration. [`integer-pairs.yml`](../../../../.github/workflows/integer-pairs.yml) replays the copies that need no local binary or store.

## How to read the table

Each copy ran after [`PREDICTION.hbp`](PREDICTION.hbp) was pushed in commit `712fab4`. [`run_cases.py`](run_cases.py) reads each case from that file, runs the copy at below normal priority, and compares its printed rows with the named rows, clock fields masked: `secs`, `secs_wall`, the random `keys` of `reader_controls`, and the output path of `WROTE`. Each row of [`RUNS.hbp`](RUNS.hbp) has the copy's hash, its exit, the number of rows compared and whether they match.

`original-runs/` holds the printed rows of the originals rerun unchanged before the prediction, by [`ORIGINALS.hbp`](ORIGINALS.hbp), with their results in [`ORIGINAL-RUNS.hbp`](ORIGINAL-RUNS.hbp). `baseline/` holds the printed rows of the earlier integer runs of `REDO-RUNS.hbp`, and the second seat's `c6_count.out`. `copy-runs/` holds what each copy printed. `inputs/own34.out` is the second seat's output that `own34_post.py` reads, byte-identical, so that replay needs no local file.

## Scope and open items

- `perron_climb_integer.py` has climbed only the 2×2 store. A climb on the 3×4 store takes it through full `perroncert` passes, which this work leaves alone. When a climb next runs on that store, this is the file to run.
- Executed 0 times in these runs: the two `qdiv` of `c4b_open.py`, after its exit 2 at the five-threshold step, and two of `c7_receipts.py`, behind `if False`. `test_intpair.py` covers the class they call.
- `c3_random.py`, `c7_receipts.py`, `own34_post.py`, the vector review's copies, `cap_check.py`, `product_bound.py scan 4`, the seat files and `replay.py` replay on hosted Linux in `integer-pairs.yml`. The other copies read binaries and stores on this machine, so they replay only here. `no-float.yml` regenerates all 25 byte-exact on every pull request.
- `integer_only_audit.py` reads names, so an aliased `from fractions import Fraction as F` passes it, and the gate is what flags that import. `test_intpair.py` reads one audit hit, its reference class, and stays out of the audit line in CI.
- The wall times in `RUNS.hbp` are from a machine also running other work at the same priority, so they say how long each run took. The cost against `Fraction` at equal load is OPEN.
- `allpairs/failclosed/reproduce_pin_run.sh` reads a different hash from its `RESULT_FILE` row, the only one of the 196 that does. Commit `9c2c7e6` changed that file after the row was written, and this work leaves both as they are.
- The companion repository `Finite-Universe-SU-N-solved` carries its own copy of the gate, unchanged here.
