# Integer pairs and integer clocks

The operator was told: "Moving those fractions to integer pairs, and three live tools' timers to integer clocks, is on the open list". He answered: "handle the integer problem". His standing word on floating point: "Floating point should be redone to integer only. Not like redone as if erase the evidence, but say, hey, we need to do this again in integer only so that it works."

## What this holds

**The class.** [`intpair.py`](../../../scripts/intpair.py) is an exact signed reduced pair of Python ints. Division is the named function `qdiv(a, b)`. A float, complex, `Decimal` or `Fraction` raises `TypeError` from every operator and comparison, `==` and `!=` included, and from a dict lookup that reaches a pair by its hash. A string or `None` raises it from arithmetic and ordering, and `==` reads them as unequal, as on any Python object. `limit_denominator` and `round` take int or `IntPair`. A fractional power or a float format spec raises `TypeError` too. Its `hash()` agrees with CPython's rational class value for value, so sets and dicts iterate in the same order, and `hash(IntPair(n)) == hash(n)`.

**Its test.** [`test_intpair.py`](../../../scripts/test_intpair.py) runs every operation on both classes and compares value, kind and exception type. MEASURED: seeds 27, 28 and 29 at 200,000 rounds each, 52,564,011 comparisons, 0 failures, with values up to 3,000 bits, negative denominators, zero and denominators that are multiples of the hash modulus. `--teeth` breaks the class 19 ways, and all 19 are seen. It is the one live file that imports `fractions` and `decimal`: the first is its reference, and each gives values the class must refuse. It makes two deliberate floats, `half` and `4 * half`, for the same purpose.

**The rewriter.** [`make_integer_pairs.py`](../../../scripts/make_integer_pairs.py) writes each copy from its original, comments and layout kept. By syntax tree, with the gate's own path-join rule, `a / b` becomes `qdiv(a , b)` and `x /= y` becomes `x = qdiv(x, y)`. The `fractions` import becomes `intpair`, with a `sys.path` line so the copy finds `native/scripts` from where it sits. Every other edit is a text pair in its table, asserted by count. A second path makes the same edits on the syntax tree and the two must dump the same. The second seat's four fuzzers go through [`make_integer_redo.py`](../3x4_stream/perron/second-seat/integer-redo/make_integer_redo.py) first, so that chain still reproduces. MEASURED: 25 copies, 35 divisions moved, regenerated byte-exact on Python 3.12, 3.13 and 3.14, each with 0 audit hits. 15 copies read 0 gate findings, and 10 read the count their list row states: `import struct` with integer formats, and in `reader_controls.py` also `__import__("math").gcd`.

## How to read the table

Each copy ran after [`PREDICTION.hbp`](PREDICTION.hbp) was pushed in commit `712fab4`. [`run_cases.py`](run_cases.py) reads each case from that file, runs the copy, and compares its printed rows with the named rows, clock fields masked: `secs`, `secs_wall`, the random `keys` field of `reader_controls`, and the output path of `WROTE`. A case with no rows to compare is a miss, and so is a run with no cases. The runner was launched at below normal priority here, which its children inherit, and hosted runs take the runner's default. Each row of [`RUNS.hbp`](RUNS.hbp) has the copy's hash, its exit, the number of rows compared and whether they match. The rows show that each script still prints what it printed. `test_intpair.py` is the instrument that carries the class: the second seat planted 11 class breaks against the 10 hosted cases that use pairs, 3 went red, and at seed 27 the test killed 262 of 280 syntax-tree mutants, with 2 crashed and 16 surviving, 15 of those equivalent by its reading. The 16th is the gap the check `half ** Q(2)` now closes.

`original-runs/` holds the printed rows of the originals rerun unchanged before the prediction, by [`ORIGINALS.hbp`](ORIGINALS.hbp), with their results in [`ORIGINAL-RUNS.hbp`](ORIGINAL-RUNS.hbp). `baseline/` holds the printed rows of the earlier integer runs of `REDO-RUNS.hbp`, and the second seat's `c6_count.out`. `copy-runs/` holds what each copy printed. `inputs/own34.out` is the second seat's output that `own34_post.py` reads, byte-identical, so that replay needs no local file.
