## 2. An explicit degree-n exact rational trial

Let R=A Y-B be the complete Q residual of any fixed 8-column
accepted trial Y, with B=QHP, and define b=10^9,
A_int=bA. Let g_num=b*g, h_num=b*h, and

    s=g_num+h_num,
    d=h_num-g_num=373931800000.

Define polynomials with **integer coefficients**

    P_0(X)=1,
    P_1(X)=s-2X,
    P_(n+1)(X)=2(s-2X) P_n(X) - d^2 P_(n-1)(X).

Define positive integers K_n=P_n(0) by

    K_0=1, K_1=s,
    K_(n+1)=2s K_n-d^2 K_(n-1).

These are scaled Chebyshev polynomials:
P_n(X)=d^n T_n((s-2X)/d).

Since P_n(0)=K_n, the following is an integer-coefficient polynomial
of degree n-1 (exact symbolic polynomial division, no inverse needed):

    F_(n-1)(X) = (K_n-P_n(X))/X.

Construct the **actual whole-Q rational-polynomial trial**

    Y_n = Y - (b/K_n) F_(n-1)(A_int) R.

It is specified by the original finite operator and can be evaluated
with repeated sparse matrix actions if state coefficients are needed.
The complete residual identity holds EXACTLY:

    A Y_n - B = P_n(A_int) R / K_n.

Since A_int has spectrum in [g_num,h_num] and the spectral theorem holds
in the W metric, the scaled Chebyshev polynomial obeys

    -d^n I <= P_n(A_int) <= d^n I,

hence its squared full-Q residual **matrix** satisfies

    R_n*R_n <= (d^n/K_n)^2 R*R.

The bound is a positive-semidefinite 8x8 matrix inequality for **all**
flat test directions at once, not merely one fixed pair. No term from
