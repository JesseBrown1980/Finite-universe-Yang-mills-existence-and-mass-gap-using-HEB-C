## HTTP-0 and matrix-law integration

The native Rust 1.81 HTTP-0 portal already reserves virtual addresses 81 (historical Perron), 82 (historical full rebuild), and 83 (historical all-pairs). Retain these as immutable source references. A fresh full replay must receive new explicitly identified evidence, not overwrite those old addresses or relabel an index lookup as computation.

A 3^10 = 59,049-row ternary checkpoint partition gives **771 sequential leaves** for 45,508,080 rows. Each checkpoint must record exact row ranges, original bytes consumed, state hashes, and a separately pinned root. Freeze/play can resume authenticated leaves without skipping or duplicating row checks.

Pascal's pyramid and the Frobenius collapse (A+B+C)^(3^k) = A^(3^k)+B^(3^k)+C^(3^k) work for **commuting operations in characteristic 3**. Our independent 27-ring test verifies that special case. The integral weighted Yang-Mills Hamiltonian does not automatically satisfy it. No general 16-cubing shortcut for 45 million rows is claimed. Backward replay requires an invertible update.
